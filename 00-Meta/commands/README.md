# Commands

Claude-native versions of PM-Brain's workflow commands. All commands work in both **Claude Code** (repo context) and **Claude Projects** (conversational context). 

## How to trigger

**In Claude Code:** Type the command name in your message, e.g. "run /braindump" or just "/braindump"
**In Claude Projects:** Same — type the command and Claude will follow the workflow defined here

## Command index

| Command | What it does | Best for |
|---|---|---|
| `/braindump` | Product sense coaching — think before frameworks | Starting any decision or problem |
| `/day` | Daily planning ritual | Morning startup (or let a scheduled task run it) |
| `/week` | Weekly review + planning | Monday/Friday rhythm (or let a scheduled task run it) |
| `/focus` | Cut through noise, prioritize | When too much is competing for attention |
| `/navigate` | Find the right framework for your situation | When you know the problem, not the approach |
| `/framework` | Match braindump to framework + template | After braindump, ready to structure |
| `/start` | Launch a new initiative end-to-end | Beginning of any new workstream |
| `/pm-review` | Review a doc for quality and alignment | After drafting any artifact |
| `/evaluate` | Deep quality check on an artifact | Before sharing PRDs, briefs, roadmaps |
| `/unstuck` | Diagnose what's blocking you | Mid-work when something isn't moving |

## Cowork overlap note

`/day` and `/week` have Cowork equivalents (Monday Morning Briefing, Friday KPI Pulse). 
- Use **Cowork** when you want it to run automatically without you present
- Use **/day or /week** when you want an interactive planning conversation
Both are worth having.
