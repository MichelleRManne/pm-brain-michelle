# /unstuck

Diagnose what's blocking you and get a concrete action plan to move.

## What Claude does

1. **Asks you to describe the block**
   - What are you trying to do?
   - What's stopping you?
   - How long have you been stuck?

2. **Diagnoses the root cause**
   Matches your situation to one of seven categories:

   | Category | Symptoms | First move |
   |---|---|---|
   | A — Direction unclear | Don't know what to build, strategy feels off | OKRs, pre-mortem, `/braindump` |
   | B — Too many priorities | Everything feels urgent, can't focus | Eisenhower, saying no, `/focus` |
   | C — No customer insight | Building on assumptions, no validation | Research, JTBD, interviews |
   | D — Stakeholder misalignment | Conflicting asks, no buy-in | Stakeholder map, one-pager, escalation |
   | E — Execution chaos | Dropping balls, context switching, reactive | Daily rituals, context zones, `/day` |
   | F — Decision paralysis | Can't commit, going in circles | Pre-mortem, one-way/two-way doors |
   | G — Team dysfunction | Ownership unclear, trust issues | Disagree-and-commit, alignment check |

   Reference: `02-Methods-and-Tools/2.0-Foundations/2.0.1-Mental-Models/6-Product-Sense-Development/3-product-sense-evaluation.md`

3. **Builds an action plan**
   - This week: 1–2 must-do actions to break the block
   - Next 2 weeks: follow-through steps
   - Frameworks to use with file pointers
   - Commands to run next

4. **Flags potential biases**
   - If the block involves a decision: surfaces relevant cognitive biases
   - Reference: `02-Methods-and-Tools/2.0-Foundations/2.0.2-Bias/1-bias-framework.md`

## Output

- Primary issue and root cause (one of A–G above)
- Symptoms present in your situation
- Action plan: this week must-do + next 2 weeks
- Frameworks and file pointers to use
- Commands to run next
- Biases to watch for

## When to use

- When something hasn't moved in more than a week
- When you feel busy but not productive
- When a conversation keeps going in circles
- When you're not sure why something feels hard

## Related commands

- `/navigate` — for a different angle if unstuck doesn't crack it
- `/focus` — if the block is category B (too many priorities)
- `/braindump` — if the block is category A (direction unclear)
- `/day` — if the block is category E (execution chaos)
