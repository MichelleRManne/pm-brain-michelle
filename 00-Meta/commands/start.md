# /start

Launch a new initiative end-to-end. From first thought to execution plan.

## What Claude does

Runs braindump and bias check first — think before structure, always.

Then walks through phases:

**Phase 0 — Braindump + bias check**
- Raw thinking first (see `/braindump`)
- Surfaces assumptions, risks, uncomfortable questions
- Reference: `PRODUCT-SENSE-RULES.md`

**Phase 1 — Foundations**
- Mental models check: is this a one-way or two-way door?
- Pre-mortem: what would make this fail?
- Reference: `02-Methods-and-Tools/2.0-Foundations/2.0.1-Mental-Models/1-Decision-Making/`

**Phase 2 — Early thinking**
- Opportunity assessment
- Create initiative folder in `04-Initiatives/`
- Reference: `02-Methods-and-Tools/2.2-Discovery/2.2.4-Opportunity-Assessment/`

**Phase 3 — Strategy alignment**
- How does this fit the roadmap and OKRs?
- Who are the stakeholders and what do they need?
- Reference: `02-Methods-and-Tools/2.1-Strategy/`

**Phase 4 — Discovery**
- What research do you need before specifying?
- JTBD, user interviews, validation
- Reference: `02-Methods-and-Tools/2.2-Discovery/`

**Phase 5 — Specify and plan**
- PRD, personas, metrics, roadmap
- Reference: `02-Methods-and-Tools/2.3-Execution/2.3.4-PRD/`

**Phase 6 — Execution and communication**
- Daily/weekly rhythm, stakeholder updates
- Reference: `/day`, `/week`, `02-Methods-and-Tools/2.4-Communication/`

**Phase 7 — Validate and iterate**
- How will you know it's working?
- Metrics instrumented, feedback loops set up

## Output

- Initiative name and one-line summary
- Completed phases checklist
- Files created in `04-Initiatives/[initiative-name]/`
- Next actions: immediate + upcoming 2 weeks
- Watch items: risks to monitor

## When to use

- When you've identified a new problem worth pursuing
- When you're assigned a new workstream and need to get organized fast
- When a parking lot idea gets promoted to a real initiative

## Related commands

- `/braindump` — always runs first inside /start
- `/focus` — if you need to clear space before starting something new
- `/navigate` — if you get stuck in any phase
- `/pm-review` and `/evaluate` — at Phase 5 before sharing artifacts

## Cowork note

Once an initiative is live, an on-demand requirements-sharding task can take your finalized PRD and turn it into tracker-ready stories, if your issue tracker is connected.
