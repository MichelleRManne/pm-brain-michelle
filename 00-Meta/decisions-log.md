# Decisions Log

Running log of product, strategy, and toolkit decisions. Append with "log this decision" in any Claude session, or run `/log-decision` for a structured capture.

---

## Format

| Field | Description |
|---|---|
| **Date** | YYYY-MM-DD |
| **Decision** | One sentence — what was decided |
| **Rationale** | Why this over alternatives |
| **Alternatives considered** | What else was on the table |
| **Status** | `decided` · `provisional` · `revisit by [date]` |
