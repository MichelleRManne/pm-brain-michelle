# .incoming/

Drop raw notes here throughout the day. If you set up the nightly synthesis scheduled task, it will process these and output a synthesized summary to `06-Weekly-Ops/`.

**Naming convention:** `YYYY-MM-DD-[topic].md`

Examples:
- `YYYY-MM-DD-eng-standup-notes.md`
- `YYYY-MM-DD-stakeholder-call-ops.md`
- `YYYY-MM-DD-random-thoughts.md`

---

Files in this folder are **inputs**, not outputs. They are not organized or polished. That's fine — the synthesis task handles it.
